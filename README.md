# personal-website-v2

Rahul Singh's personal site: one dark 3D world built around a single object that turns out to be Rahul's career.

**Status:** the plain site is built (content layer, the Index, prerendered HTML). No 3D yet.

Node 24 and pnpm. `pnpm install`, then `pnpm dev`. Also: `pnpm build`, `pnpm typecheck`, `pnpm lint`, `pnpm format`.

Start with [CLAUDE.md](CLAUDE.md), then [docs/VISION.md](docs/VISION.md). Current progress and next steps are in [docs/ROADMAP.md](docs/ROADMAP.md).
